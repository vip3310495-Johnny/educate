## 實作與驗收紀錄

- Modern Web Guidance：網頁實作前實際載入的技能、search／retrieve 指引 ID 或官方來源、採用項目與降級；技能／來源不可用時的缺項與替代查核。
- Google Chrome：目標平台／版本、支援證據、是否使用實際 Chrome、驗收範圍與結果、降級及限制；狀態 `Pass`／`Issues found`／`Not verified`。
- Microsoft Edge：目標平台／版本、支援證據、是否使用實際 Edge、驗收範圍與結果、降級及限制；狀態 `Pass`／`Issues found`／`Not verified`。不得由 Chrome 或一般 Chromium 結果推定通過。
- 可移動物件裁切檢查：逐頁／逐物件記錄素材邊界、桌面與手機的起始／中途／結束／重播、最大旋轉／縮放、意圖性遮擋／離場、問題修正與複驗結果。
- 跨頁故事連續性檢查：再次確認開頭背景與採用版本；逐組記錄「本頁結尾 → 次頁開頭」的因果、時間、地點、人物動機／去向、已知資訊及物件狀態；列出刪除的贅述、過渡句與缺漏補寫，以及正文／朗讀／分鏡同步更新結果。
- 分層資產、動畫／音效時間線與重播策略：
- 動畫起始、變化與完成狀態；有裝載時，從空載到裝滿再連同貨物離場的可見過程：
- 圖上互動點：每個可互動元件的可見標記、圖片相對位置、觸控範圍與對應動作；逐一測試圖上點按及手機定位，不以底部按鈕取代。
- Taste 桌面／手機檢查尺寸、問題及修正：
