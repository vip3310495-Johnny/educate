# storybooks maker

以幼兒與家長共讀、一起操作為預設情境。使用繁體中文；依使用者指定調整語言、年齡、頁數與風格。保留已確認的故事與角色設定。

## 1. 接續目前進度

先辨識正在進行「新書規劃、已核准製作、局部修改、排版改善、交付部署」哪個階段。

- 修改既有作品時，先讀取最新原始檔、已確認內容及目前網站狀態。沿用原檔與網站身分，不憑對話摘要重建舊版本。
- 把最近要求整合進既有目標；記錄已核准範圍，避免修改風格時遺失互動、音效或故事修訂。
- 有「可以動手、直接實作」等明確授權，就接續製作，不重跑確認流程。局部修正不必重新核准整本書。
- 沒有特別要求時，採 8–10 頁與親子共讀語氣。資訊足夠便先做可交付的規劃；只詢問會實質影響故事的缺項。

## 2. 依素材狀況，先交文本與必要的圖片

讀取 [分鏡與分層美術](references/planning-and-art.md)，以 [製作規格模板](assets/production-brief.md) 記錄決策。

不論是否已有視覺素材，撰寫或重修正文前，**有原作或相關影視參考版本就必須實際查閱並作為改編依據**，優先採用使用者指定的版本，記錄來源與取捨，不只憑記憶拼湊劇情。**正文開頭先交代主角的必要背景、人物關係、生活處境與行動起因**；原作未交代的身世不可擅自當成原設定。逐頁寫清楚事件的原因、行動與結果，補足轉場及關鍵資訊，在交付分鏡前先完成一次全篇連讀與邏輯檢查。具體查閱、版本整合與文本檢查方式見上述分鏡規範。

先查看使用者提供的附件、圖片與指定資產。此處「素材」指圖片、角色、背景等視覺資產；只有故事題目或情節描述，仍屬未提供視覺素材。依下列兩條路徑準備確認稿：

- **沒有提供素材：**先產生故事摘要、角色設定與逐頁完整正文，並用圖片生成工具生成圖片素材／逐頁插畫預覽或清楚的分鏡縮圖。把圖片與文本一起交給使用者確認。
- **已提供素材：**先讀取、檢視素材，以素材為基礎生成故事摘要與逐頁完整正文，標明每頁對應素材。此階段只生成文本，不另生成、重繪或去背圖片。素材若不足或尚未分層，記錄需於實作階段處理的項目，不在確認前自動補圖。

兩條路徑都提出每頁 1–3 個互動構想，讓使用者能確認故事如何展開。使用者若明確要求另外生成圖片或只做文字規劃，依其要求調整。

在尚未獲准實作時，完成這份可審閱的預覽後停在確認點。若使用者明確要求本輪只做文字規劃，依其範圍交付即可。確認後只重做受修改影響的分鏡，並接續最終資產與程式。

## 3. 生成真正可動的分層資產

自行生成的確認稿只作為角色、畫風與構圖參考；確認後重新生成最終背景、透明角色／道具與遮擋前景，不把整頁預覽直接當成最終可動場景。使用者提供的可用素材優先沿用；進入已核准實作後，才依互動需求處理必要分層、去背或補圖，維持其原始視覺內容。

- 背景不要烘焙進會移動、消失或破壞的角色和道具，避免動作後留下重影。
- 維持全書角色造型、服裝、比例、光線與畫風一致；分清固定物、活動物與前景遮擋。
- 各頁人物依情節採用不同姿勢、表情與視角，不以同一人物圖反覆貼用；核對腳、座椅、桌面等接觸與遮擋，以及視線、手勢和實際道具的位置。
- 依動作拆屋頂、屋身、門、材料等；檢查透明 alpha、裁切邊界與陰影。
- 用圖片生成工具處理圖片創作、重繪及去背；格式轉換、壓縮與透明邊界量測可程式化處理。

## 4. 實作互動、配樂與朗讀

讀取 [互動與音訊](references/interaction-and-audio.md)。

- 每頁安排 1–3 個與情節有因果關係的互動點。點按能觸發大幅位移或清楚可見的特效；微小晃動不算完成。
- **每個可互動元件都必須在插畫上的對應位置有可見、可直接點按的互動點。** 以圓點、編號或清楚標記提示角色／道具的位置；手機也要看得見、按得到。下方文字按鈕可保留作為替代入口，但不能取代圖片上的互動點；兩者觸發同一個動作與音效。
- 每次位移與特效搭配相符音效，聲音時間點對準動作。提供觸控、滑鼠與鍵盤可操作的入口及重播／重設。
- 動畫須看得出起始、變化與完成狀態；裝載情節要呈現空載到裝滿，貨物跟隨載具真正離場，不能只改文字或重播開頭動畫。
- **每次成功翻頁都播放柔和的紙張翻頁音效，與換頁動作同步。** 上一頁／下一頁按鈕、鍵盤、觸控滑動、目錄跳頁及故事觸發的自動翻頁共用同一處播放邏輯，每次換頁只播一次，並受音效開關與音量控制；未實際換頁時不播放。翻頁不計入每頁 1–3 處故事互動。
- BGM 優先選用符合故事情境的世界名曲；確認樂曲與具體錄音均允許本次離線交付或網站分享，保存來源與署名。無合適名曲錄音時再選其他授權素材，仍找不到才自行創作。
- 配樂符合故事與場景氣氛；音樂、音效分開控制；由使用者手勢啟動音訊。朗讀時降低 BGM，離開頁面停止舊音訊與排程。
- **朗讀只讀故事正文，不讀書名、頁標題、頁碼、操作提示或署名。** 使用明確的正文資料來源，不以整頁 `innerText` 組合語音。

## 5. 必須使用 Taste 優化排版

讀取 [Taste 與字體排版](references/taste-and-layout.md)，並實際讀取、套用當下可用的 Taste 工作流程。

1. 在技能清單中找 `engineering-suite-taste:entry-taste` 或同插件的 `entry-taste`；讀取入口後依其路由載入 `design-taste-frontend`。使用當下提供的技能位置，不寫死環境別名或安裝路徑。
2. 在建立畫面布局前套用其原則；互動完成後再次以 Taste 檢查實際桌面與手機畫面，修正並複驗。
3. 以閱讀體驗約束設計：圖文比例、段落、留白、按鈕層級與翻頁動線清楚。保留已核准故事；不要為套用通用網站風格而重寫劇情或換掉已核准素材。
4. 全書統一使用易讀的繁體中文無襯線黑體；標題、正文、按鈕、頁碼、彈窗與特效文字都適用。不得使用新細明體或襯線字體回退。
5. 在製作紀錄簡記實際使用的 Taste 流程、主要排版決策及檢查尺寸。僅寫「已美化」不算完成。

翻頁按鈕放在插畫上方，手機首次開啟便看得見；使用清楚的左右實心三角形，分別表示上一頁／下一頁，不用方塊或矩形底板。三角形外保留至少 44 × 44 CSS px 的透明點按範圍，幼兒操作以約 60 × 60 px 為起點；保留鍵盤焦點、停用狀態、首末頁行為及翻頁音效。

移除「點畫面上的①②，一起把故事玩出來」等重複操作口號，將插畫下方空間留給可供爸媽說故事的敘述、角色對白及互動後的情節回饋。原動畫文字框的故事內容移到圖片外的固定閱讀區，字級與正文相近；保留圖上互動點、必要控制與無障礙名稱。圖中文字、懸停及焦點標籤不得遮住人物或動作；無法安全避讓時移除可見文字，不以浮動框重新占用畫面。

若 Taste 未出現在當前清單，先用技能／插件探索找同一工作流程。確實無法取得時，說明 Taste 步驟尚未完成；完成其他已授權且不依賴它的工作，不宣稱已套用。

## 6. 驗收與交付

讀取 [實作、驗收與交付](references/implementation-and-qa.md)。依變更範圍進行必要驗證，不為局部字句修改重做整本書。

- **完成前逐一檢查所有可移動物件是否有裁切問題。** 同時檢查素材本身與實際畫面，在起始、移動途中、結束及重播狀態驗證完整輪廓；涵蓋縮放、旋轉、容器遮罩與手機版。區分劇情需要的遮擋／離場與意外切掉的部位，修正後複驗。
- **完成前從頭連讀每一頁正文，確認角色背景已交代，故事連續且符合邏輯。** 對照已查閱的原作／影視版本與核准的改編取捨，核對前頁結果能否接上次頁開頭，以及時間、地點、人物動機、已知資訊與物件狀態是否連貫；補上必要的過渡句或缺漏交代，刪除重複贅述，保留已核准主線。兩項皆須留下實際檢查與修正紀錄，不能只列為待辦便宣稱完成。
- 逐頁確認人物姿勢、接觸面、視線、道具、情節與互動一致；在動畫開始、中途、結束、重玩及換頁後驗收，含裝載物隨載具離場與音效節奏。
- 實測桌面、平板與窄手機：文字可讀、無橫向溢出、操作可達、無遮蓋正文；確認實際字型已載入。
- 手機實測翻頁入口首次可見、觸控位置與動態遮擋；檢查懸停／焦點狀態，確認敘事文字在圖片外且沒有重複操作口號。
- 交付單一離線 HTML 時，內嵌插畫、音效、BGM、CSS、程式與字型，離線驗證；系統朗讀依裝置語音能力提供，缺少時正常降級。
- 查核 BGM／字型授權與署名。未能實際聽測的朗讀不得標成已聽測。
- 使用者要求網站或部署時，採當下可用的 Sites 工作流程；更新既有網站並保留網址、權限及分享設定。僅要求下載檔時不擅自公開。
- **故事書或後續修訂完成後，預設將最終離線 HTML、含完整資產的原始碼 ZIP、最新腳本／分鏡上傳使用者的 Google 雲端硬碟，不必等使用者再次提醒。** 除非使用者明確要求不上傳或指定其他目的地，將此步納入交付；沿用已指定或已存在的該書資料夾與檔案身分，更新既有版本，驗證成功後提供雲端連結。只做分鏡／文字預覽時，不提前上傳未完成的互動書。具體保存與核對方式見交付規範。
- 依環境的持久保存規則交付下載檔；更新既有檔案時保留身分並避免覆蓋他人的更新。不要把憑證或私人網站識別資料寫進可分享檔案。
- 最後提供實際可開啟的作品／下載連結、簡短完成項目及必要限制。只有成功完成部署與保存後才宣稱交付完成。
