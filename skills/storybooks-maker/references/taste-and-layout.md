# Taste 與字體排版

## 實際套用 Taste

把 Taste 當成必須執行的設計步驟，而非參考名稱。

1. 依當前技能清單找到 Taste 的 `entry-taste`，讀取後按其路由載入 `design-taste-frontend`。如有明確特殊風格需求，再加入入口指定的其他子流程。
2. 在排版實作前，整理該書的情緒、主視覺、字體、閱讀順序及互動入口，形成少數一致的設計決策。
3. 在完整頁面可操作後，用實際截圖與 UI 檢查再次套用 Taste，修正文字、留白、比例、對比與手機適配。
4. 保留檢查紀錄：載入流程名稱、主要決策、檢查尺寸、發現問題及修正結果。不要把只讀文件等同於完成設計驗收。

使用者既有內容與本書閱讀需求優先。Taste 的通用網站建議應轉成適合兒童繪本的介面；不要強套行銷標語、儀表板卡片、工業風、英文標籤或額外裝飾。

## 統一字型

選一套有完整繁體中文字形、可合法嵌入的無襯線字型。可採 Noto Sans CJK TC 等；實際使用前檢查取得來源及授權。全書使用同一家族，以粗細、字級、顏色分層，不混入另一套標題字體。

以內嵌／自託管字型確保跨裝置一致，設定全域變數並讓所有控制項繼承：

```css
:root { --book-font: 'StorySansTC', 'Noto Sans TC', sans-serif; }
body { font-family: var(--book-font); }
button, input, select, textarea { font: inherit; }
/* 動態特效、對話框與獨立 svg text 也要明確繼承／設定。 */
```

`StorySansTC` 只是自訂家族名稱範例；必須真的對應到合法的字型檔。禁止 `新細明體`、`PMingLiU`、`MingLiU`、`Songti`、`Georgia` 與 generic `serif` 回退。做自動檢查時解析完整字型名稱與 fallback token，避免把 `sans-serif` 誤判成 `serif`。

字型子集需包含：全書正文、標題、按鈕、目錄、共讀提示、錯誤提示、音效擬聲詞、數字、標點與動態特效文字。修改文案後重新產生子集；保留授權檔與必要的 Reserved Font Name 規則。字型工具或 WOFF2 壓縮套件不可用時，可以改用受支援的 WOFF，不能因此讓文字退回未知字型。

檢查 `document.fonts.ready`、`document.fonts.check(...)`、實際載入資源及截圖；CSS 中寫對 family 名稱不代表成功載入。離線版 CSS 的字型 `url(...)` 也必須內嵌，不得只內嵌圖片與音樂。

## 圖文與操作布局

讓插畫是主要視覺，正文有獨立、安靜的閱讀區。以紙張色、故事主題色、有限的陰影及一致圓角建立書本感；避免過多小標、徽章、卡片套卡片與裝飾。

可從以下配置起步，再依素材比例調整：

- 桌面：翻頁列放在插畫上方；左側插畫舞台、圖外敘述及互動按鈕，右側標題、正文、朗讀與重播。
- 手機：翻頁→插畫→圖外敘述→正文→互動按鈕；首次開啟即可看見翻頁入口，不必先捲到底。保留自然捲動，不用固定高度硬壓全文或把操作擋在畫面外。
- 平板／橫向：依可用高度選單／雙欄，避免橫向手機誤套桌面布局造成舞台或正文裁切。

以桌面正文約 20 px、手機 18–19 px、行高約 1.8–1.95 作起點；標題約 26–36 px。依長度及尺寸調整，不讓短故事被空白切碎，也不為塞滿一屏縮成小字。

正文對比至少達 4.5:1，通常可做得更高；次要提示仍需清楚。互動入口足夠大，標籤描述動作，例如「幫忙疊磚塊」，不只寫「互動」。焦點、按下、停用與播放狀態要能辨識。

翻頁控制以左右實心三角形呈現，讓孩子直接辨認方向。移除方塊／矩形底板及其懸停底色，三角形本身須與背景有足夠對比；可用顏色或輕微位移回饋按下。可點按範圍至少 44 × 44 CSS px，可用透明容器擴大，不把實際觸控範圍裁成小三角形。保留清楚的鍵盤焦點、停用外觀與「上一頁／下一頁」無障礙名稱；末頁若提供再讀一次，同步更新名稱及提示。桌面與手機皆使用同一三角形樣式，換頁仍走共用音效邏輯。

幼兒操作以約 60 × 60 CSS px 的翻頁觸控範圍為起點。翻頁列置於圖片外且位置穩定，短橫向與窄手機也要一眼看見；不用漂浮按鈕蓋住人物。

## 把提示空間留給故事

移除「點畫面上的①②」「一起把故事玩出來」等通用操作口號與重複教學。互動入口以圖上的可見標記、明確按鈕及無障礙名稱傳達；必要的聲音設定或錯誤說明留在對應控制區，不刪除可操作性資訊。

把原本動畫文字框中的故事敘述、祝福、角色對白及動作結果移到插畫正下方的固定閱讀區，讓爸媽順著畫面說故事。字級、對比及行距與正文相近，不能縮成小字狀態列或塞到所有按鈕後面。初始呈現適合當頁的敘事句，互動後更新對應情節；不用「請點②」等操作指令占回空間。敘述應與當下場景和動畫進度一致，避免重複整段正文；換頁／重玩恢復該頁初始內容，保持手機閱讀位置穩定。

動畫提示優先放在圖片外；圖內文字框與懸停／焦點標籤都要檢查角色臉、手、道具及完整移動路徑。無法保證避讓時移除可見文字，保留互動點與 `aria-label`；不要只檢查靜止畫面或把文字換位置後仍遮住另一人物。春聯、招牌等故事中的實體文字按情節保留。

## 視覺驗收

至少檢查桌面、平板約 820 px、窄手機 360／390 px 及短橫向畫面。可合併代表尺寸，但要覆蓋使用者裝置與最長正文頁。

逐一確認：沒有水平溢出、字體與粗細一致、段落可讀、正文不被浮動工具列遮住、熱點不擋角色臉部、翻頁入口首次可見、最後一頁操作可達。檢查動畫開始、中途、結束、重玩及換頁後的文字與布局，包含懸停／焦點觸發時；圖外敘述不應推擠圖片或遮擋操作。

檢查封面、最長正文、最複雜動畫與結尾。UI 操作後必要時再觀察一次截圖；不要把尚未更新的舊截圖誤判成操作失敗。截圖要與最終保存／部署的版本一致。
