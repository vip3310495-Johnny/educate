# 互動與音訊

## 互動契約

每頁有 1–3 個**不同且有故事意義**的互動。畫面熱點和其下方的同功能按鈕算同一處；不要用重複入口灌大數量。點按觸發即可滿足需求，故事需要時再加入拖曳。每個計入數量的互動都要有大幅動作或明顯特效，不能只有其中一個達標。

為每個互動寫出：觸發物、前置狀態、起點／終點、動作時間、特效、音效時間點、結束狀態與重播方式。兩種可驗收的結果：

- **大幅移動：**角色穿越場景、材料飛散、屋頂升起、角色落入物件再跳出。可先以約 25–65% 舞台寬／高的位移設計，再依構圖調整；驗收看實際可見程度。
- **明顯特效：**裂紋逐次擴大、強光冒出、風把物件吹散、湯水濺起、星光沿路亮起。小幅晃動、單純變色或極短縮放不足以取代要求的大幅動作／特效。

在確認稿就描述可見範圍與結束結果，避免只寫「會動」「輕擺」或「閃一下」。例如把「點樹葉微晃」改成「葉片從樹冠沿弧線飛過草地，落在小豬腳邊，跟隨沙沙聲」；把微小單點閃爍改成看得清楚的星光連線或一串光點擴散。微幅呼吸、葉片晃動可當環境動態，但不占用 1–3 處互動的名額。

若有「連點幾次達成事件後自動翻頁」的情節，顯示累積狀態，完成後只觸發一次，並在換頁／重設時取消等待。

每個互動角色、道具或場景物件，都在插畫上的對應位置放置**可見且能直接點按的互動點**，例如圓點、編號或簡潔標記。預設就要可見，不依賴滑鼠懸停才出現；不能只有圖片下方的文字按鈕，也不能只放一個無法點按的裝飾標記。

以實際 `button` 實作圖上互動點，提供鍵盤焦點、清楚的 `aria-label` 與至少約 44 × 44 CSS px 的觸控範圍。視覺標記可較小，但可點範圍要足夠；避免遮住角色臉部或重要畫面，並確保前景圖層不會攔截點按。

互動點用舞台百分比或角色本身的相對座標定位，縮放、手機直橫向及角色移動時仍要對準元件；角色離場時不要留下錯位的透明點擊區，重設／重播時恢復。圖上互動點與下方對應按鈕共用同一互動函式、進度狀態與同步音效，避免事件冒泡造成一次點按觸發兩次。拖曳需提供圖上的點按替代方式；滑動翻頁不得同時觸發互動點。

## 時間線與生命週期

先定義並呈現起始、變化與完成三個可觀察狀態。裝載情節例如「空車廂→物件逐一裝入→裝滿停留→載著貨物駛離」；貨物與車輛使用共同移動容器或同步座標，離場時全部一起越過舞台邊界。不得以更新計數／文字、空車駛走、貨物留在原地或直接重播開頭動畫代替完成過程。完成後保持情節終態，明確重玩才回初始狀態；縮減動態效果也保留各狀態的因果與結果。

把動作、粒子與音效排在同一時間線。例：「0 ms 下落→600 ms 落水並播放噗通聲→650 ms 水花與短泡泡聲→1000 ms 跳出並播放躍起聲→離場」。依實際動畫調整，不能把所有聲音放在按鈕按下那一刻。

避免整條時間線使用會改變各事件相對時間的全域 easing；可以使用線性時間進度，在各動作片段內設 easing。動畫結束狀態、特效起始點與聲音時間必須逐項對齊。

每頁維護自己的 animations、timers、audio nodes、temporary elements 與 state。換頁、重設或重播時先取消上一輪；避免殘留水花、延遲音效與舊角色在新頁出現。快速連點可以忽略、重播或合併，但規則要一致。

情節回饋顯示在圖片外的固定敘事區，可使用 `role="status"`／`aria-live="polite"`，保留正文朗讀的獨立資料來源。文字隨實際進度更新，不用跳出的文字框遮人物，也不用重複操作口號取代敘述；換頁或重玩一併還原該頁內容。

用前景遮擋表現進入鍋內、穿門、躲到桌後；不要只讓角色縮小消失。縮放舞台時保持圖層錨點與音效時間不變。尊重 `prefers-reduced-motion`，保留故事結果與靜態提示。

## 翻頁音效

每次成功換到另一頁時，播放短促、柔和、可辨識紙張翻動的音效，與翻頁動畫開始或畫面切換的時點同步；不要用一般按鈕提示音代替。此音效屬於全書導覽，不計入各頁 1–3 處故事互動。

把翻頁音效放在共用的換頁流程中，涵蓋上一頁／下一頁按鈕、鍵盤方向鍵與 Home／End、觸控滑動、目錄跳頁及故事觸發的自動翻頁。每次實際頁碼改變只播放一次；目錄跨多頁仍只播一次，避免各輸入事件與換頁函式各播一遍。

首次載入、選取目前頁面、在首末頁按無效方向、未達翻頁門檻的滑動，以及原頁重設／重播都不播放。快速連續換頁時停止或短淡出上一個翻頁聲，再播放本次聲音，避免大量疊音。

翻頁音效受 SFX 開關與音量控制，獨立於 BGM 開關；BGM 關閉仍可翻頁發聲，SFX 關閉則保持安靜。遵守使用者手勢解鎖音訊與頁面隱藏暫停規則；自動翻頁僅在音訊已可用且音效開啟時播放，不繞過 autoplay 限制，也不補播先前被阻擋的聲音。

先清除舊頁的互動音訊與排程，再啟動本次翻頁聲；將它歸於導覽音效管理，避免被舊頁清理或新頁初始化立即截斷。縮減動態效果時仍可在換頁瞬間播放柔和聲音。使用授權素材時保存來源與必要署名，離線版也要內嵌此音效；若採 Web Audio 合成，確認實際聽感像紙張翻動。

## BGM 搜尋、選擇與授權

先依故事與場景的情緒，尋找適合幼兒聆聽的世界名曲（優先古典名曲）及其可合法使用的錄音版本。以曲目情緒、節奏、音量與情節轉折選擇，不因知名度硬套曲目。若沒有合適且允許本次交付方式的名曲錄音，再尋找其他授權 BGM；仍找不到才自行創作。

分開確認樂曲本身與具體演奏錄音的權利；樂曲已進入公有領域，不代表現代演奏錄音也可自由複製。優先使用來源清楚、允許本次嵌入與分享方式的錄音，並核對其授權地域及必要署名。

判斷實際使用方式：離線 HTML 含音樂檔案，網站與可下載書籍涉及複製與散布。「免費試聽／個人收聽」不能當作可嵌入分發的授權；公開網站也不能直接套用僅限私人用途的條款。

為每首入選曲目保存：曲名、作者、官方來源 URL、授權名稱與 URL、查核日期、是否允許嵌入／分發、署名要求，以及剪輯、音量、循環等修改紀錄。需要額外許可才能使用的素材不納入。

找到適合且許可清楚的素材就下載隨書提供，不以熱連結當作主要播放來源。用書內「音樂與素材」資訊及專案 credits／manifest 完整署名。不能只把授權留在對話裡。

只有在合理搜尋後，世界名曲及其他授權素材都沒有符合情緒與使用方式的版本，才自行創作 BGM；保留簡短搜尋紀錄與採用自製配樂的原因。不要因找素材較麻煩就跳過搜尋。

以少數曲目或段落覆蓋主要情緒，音量柔和，換頁淡入淡出。連續同一曲目不要每頁從頭播放。危機場景維持兒童可接受的張力，不用驚嚇式突發大音量。

## 音訊控制與朗讀

由「打開故事書」等使用者手勢初始化／恢復 AudioContext 和音樂。處理瀏覽器 autoplay 拒絕，畫面仍可讀；不要靠自動重試無限啟播。

音樂與音效提供分開的開關／音量。視窗隱藏時暫停音訊，返回後按使用者偏好恢復；朗讀時降低 BGM，朗讀結束、取消或失敗時恢復。

使用語意相符且不刺耳的 SFX：腳步、草葉、敲木、磚塊、風、倒塌、門閂、水花、泡泡與星光。短合成音效可用 Web Audio；需自然質地時選授權素材。持續拖動使用節流與循環漸變，避免每個 pointermove 觸發一個巨大聲音。

正文與標題保持獨立，從正文建立語音。例如：

```js
function narrationText(page) {
  return page.paragraphs.join('\n');
}
// 呼叫前先取消上一頁；不要串上 page.title 或整頁 innerText。
const utterance = new SpeechSynthesisUtterance(narrationText(page));
utterance.lang = 'zh-TW';
```

挑選裝置可用的 `zh-TW` 聲音、較慢語速與適度停頓；沒有合適聲音時告知限制並正常保留圖文功能。處理 `voiceschanged`、取消／錯誤與快速翻頁的競態，避免舊 `onend` 回呼改動新頁播放狀態。

系統 TTS 是否離線、是否具台灣中文聲音取決於裝置；單一 HTML 不保證內建語音模型。若要求保證離線真人感朗讀，先確定可用且允許嵌入的配音方式，生成／取得正文錄音後隨檔打包。
